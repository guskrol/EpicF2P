# EpicF2P

EpicBot script project for **F2P Goals**, an Old School RuneScape F2P progression script.

## Module

`f2p-goals` contains the script, runtime controllers, combat, skilling, questing, funding, Grand Exchange, and utility modules.

## Build

```powershell
.\gradlew.bat :f2p-goals:build
```

The EpicBot Gradle plugin copies the compiled local script output to the EpicBot scripts directory configured on the machine.

## Run Locally

Open EpicBot, refresh local scripts, and select **F2P Goals**. The running version is printed in the script overlay and startup log.
